# Assets

Curated visual assets live here when they are intentionally part of WaveSmith.

- `textures/`: reusable texture sources for procedural lines, surfaces, masks, and materials.
- `backdrops/`: reusable local background or style-frame images for presets that opt into them.
- `references/`: small reference boards or approved concept frames that guide future effects.

Use `.tmp/art/` for experiments, generated drafts, and one-off reference images that should not be
committed. Move only selected, project-worthy files into `assets/`.
